# Plan 6.3: PWA Setup (Manifest + Service Worker + Offline)

<objective>
Make EOD Flow installable as a PWA with offline caching of the app shell. Users on mobile can install the app and get a native-like experience.

Purpose: Staff checking tasks on their phones get fast, app-like performance.
Output: manifest.json, service worker, install prompt, offline caching.
</objective>

<context>
Load for context:
- EOD-FLOW-PROJECT-BRIEF.md (Section 16 — PWA requirements)
- next.config.ts (needs next-pwa wrapper)
- src/app/layout.tsx (needs manifest link + meta tags)
</context>

<tasks>

<task type="auto">
  <name>Install next-pwa and configure manifest</name>
  <files>
    next.config.ts
    public/manifest.json
    src/app/layout.tsx
  </files>
  <action>
    1. Install: `npm install next-pwa`
    
    2. Create public/manifest.json:
    ```json
    {
      "name": "EOD Flow",
      "short_name": "EOD Flow",
      "description": "Task management for End Of Day Media",
      "start_url": "/overview",
      "display": "standalone",
      "background_color": "#0A0A0A",
      "theme_color": "#6C5CE7",
      "icons": [
        { "src": "/icons/icon-192.png", "sizes": "192x192", "type": "image/png" },
        { "src": "/icons/icon-512.png", "sizes": "512x512", "type": "image/png" }
      ]
    }
    ```
    
    3. Generate PWA icons (192x192 and 512x512) — use generate_image tool to create a simple "EOD" icon with purple (#6C5CE7) background, then save to public/icons/.
    
    4. Update next.config.ts to wrap with next-pwa:
    ```ts
    import withPWA from 'next-pwa';
    const config = withPWA({ dest: 'public', disable: process.env.NODE_ENV === 'development' })({ ...existing config });
    ```
    
    5. Update src/app/layout.tsx:
       - Add <link rel="manifest" href="/manifest.json">
       - Add <meta name="theme-color" content="#6C5CE7">
       - Add <meta name="apple-mobile-web-app-capable" content="yes">
    
    AVOID: Enabling PWA in development (causes caching issues).
    AVOID: Caching API routes — only cache static assets and pages.
  </action>
  <verify>npx tsc --noEmit; manifest.json accessible at /manifest.json</verify>
  <done>PWA is installable. manifest.json configured. Service worker generated on build. App shell cached for offline.</done>
</task>

<task type="auto">
  <name>Add offline indicator banner</name>
  <files>src/components/offline-indicator.tsx, src/app/(dashboard)/layout.tsx</files>
  <action>
    1. Create OfflineIndicator component:
       - "use client" component
       - Listens to window 'online' and 'offline' events
       - When offline: shows a fixed bottom banner "You're offline — changes will sync when reconnected"
       - Brutalist styling: bg-destructive, text-on-primary, font-mono
       - Slides in/out with CSS transition
    
    2. Add <OfflineIndicator /> to dashboard layout (above or below main content)
    
    AVOID: Using navigator.onLine alone — also listen to fetch errors.
  </action>
  <verify>npx tsc --noEmit passes</verify>
  <done>Offline indicator renders when connection lost, hides when restored.</done>
</task>
